# DevOps MCP Guide

Guia practica para aprender Model Context Protocol (MCP) desde cero y aplicarlo a herramientas DevOps.

## Objetivo

Este repositorio busca servir como:

- Guia progresiva para entender MCP.
- Coleccion de ejemplos pequenos y aislados.
- Base para construir un servidor MCP DevOps completo.
- Referencia previa a una futura template reutilizable en otro repositorio.

## Estructura

```text
docs/
examples/
complete-server/
diagrams/
```

## Ruta recomendada

1. Leer la guia en `docs/`.
2. Ejecutar los ejemplos en `examples/`.
3. Revisar el servidor completo en `complete-server/`.
4. Extraer una template independiente para servidores MCP DevOps.
